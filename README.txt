HUNTER'S DESK — GITHUB PAGES SITE

Upload index.html to the root of a new public GitHub repository (suggested name: hunters-desk).
Then go to Settings > Pages > Deploy from a branch > main > /(root).

This version is self-contained: the desk artwork is embedded directly in index.html, so there is no assets folder.
The Bestiary hotspot already links to https://jastalyndragorth.github.io/bestiary/
Other hotspots currently show an Archive Access Pending message until their destination pages are ready.
